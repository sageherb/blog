## 개요

리뷰어와 작성자 각각의 입장에서 코드 리뷰 문화를 개선하는 방법을 정리합니다.

이 글에서는 핵심 개념부터 실전 적용까지 단계별로 살펴봅니다.

## 본문

실무에서 바로 적용할 수 있는 예제 코드와 함께 설명합니다.

```typescript
// 예시 코드
const example = () => {
  console.log("Hello, world!");
};
```

## 마치며

꾸준히 적용하다 보면 코드 품질이 눈에 띄게 향상됩니다.
