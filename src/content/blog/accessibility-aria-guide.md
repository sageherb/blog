## 개요

ARIA를 남용하지 않고 꼭 필요한 곳에만 사용하는 방법과 스크린 리더 테스트 방법을 정리합니다.

이 글에서는 핵심 개념부터 실전 적용까지 단계별로 살펴봅니다.

## 본문

실무에서 바로 적용할 수 있는 예제 코드와 함께 설명합니다.

```typescript
// 예시 코드
const example = () => {
  console.log("Hello, world!");
};
```

## 마치며

꾸준히 적용하다 보면 코드 품질이 눈에 띄게 향상됩니다.
